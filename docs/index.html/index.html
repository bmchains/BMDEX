BMDEX: DEX infrastructure surface

This site is deployed via GitHub Actions and served by GitHub Pages from /docs. Keep it minimal and stable: pure static HTML is intentional so it never blocks backend development.

Pages After enabling GitHub Pages to use GitHub Actions, pushes to main will redeploy automatically.

API

Current API package: apps/api (NestJS). Health endpoint: 

GET /health
→ { "service": "bmdex-api", "status": "ok", "custodial": false }

Local Default port is 4000 (PORT env override).

Security posture

Treat the API as internet-exposed by default. Enforce least privilege, strict CORS allowlists per environment, and rate limiting at the edge. Avoid shipping secrets in repo or build logs. 

# Hard rule: never commit secrets
GITHUB_TOKEN scopes: minimal
Pages workflow: read contents, write pages, OIDC id-token

Run the API

From the repo root (example):

cd apps/api
npm install
npm run dev

Next steps

When you add OpenAPI / Swagger, you can generate and publish a static API reference into /docs as part of the Pages workflow (without coupling it to runtime).

Tip Keep docs deploy fast and deterministic; avoid building the entire monorepo in Pages.
